# Black Death City Sandbox

**BDC-Sandbox** is a collection of utilites for testing combat scenarios in Sam Pearson's Black Death City skirmish game using Luca Carbone's GameMaster library.

## Black Death City

**Black Death City** is a miniatures-agnostic narrative skirmish wargame set in a ruined city beset by plague written by Sam Pearson.

More information and beta rules can be found on the official website at: [Black Death City](https://www.blackdeathcity.com)

## GameMaster Core

**Game-Master-Core** is an RPG framework for Godot 4 built on traditional tabletop-RPG principles written by Luca Carbone.

The original README file is included here: [README_GM_CORE](README_GM_CORE.md)
The original Github repository can be found at: [Game-Master-Core Repository](https://github.com/tndwolf/Game-Master-Core)
